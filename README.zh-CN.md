# AE 黑白叙事歌词 PV 技能

简体中文 · [English](README.md) · [MIT 开源协议](LICENSE)

这是一个面向 Codex 的歌词 PV 制作技能：使用 Adobe After Effects 原生图层、表达式、关键帧和按项目编写的脚本，把全片参考分析、歌词节拍对齐、黑白漫画视觉、动态文字与成片验证串成完整流程。

**仓库仅包含制作方法。没有歌曲、现有歌曲的歌词、插画、立绘、截图、品牌标志、字体文件、成片或 AE 工程。每个新项目都重新创作视觉素材；参考视频仅用于分析，不从中提取画面或素材用于成片。**

## 技能包含什么

- 按完整时间轴分析参考视频，再对动作区间加密检查，不只挑选几个关键帧。
- 创作有诗意、可带自嘲的屏幕歌词，按人声乐句对齐，同时保留当前项目选用的音频。
- 使用黑白插画、大字中文排版、低调信息栏、细线、左右交替构图与克制的转场。
- 以独立的文字、图像、形状和动画图层，搭建可编辑、无需第三方插件的 AE 工程。
- 先验证短片技术样例和代表性副歌，再进行全曲渲染。
- 检查完整解码、歌词时间、素材链接、文字可读性，并说明实际达到的音频保真程度。

这是指导制作的技能，不附带固定渲染器或可复用的媒体素材包。分辨率、帧率、主题、预算和构图按项目决定；1080p/60 fps 只是可调整的建议配置。

## 安装到 Codex

在 Codex 中让内置安装技能执行：

```text
$skill-installer 安装这个仓库中的技能：https://github.com/yifanchen12/ae-kinetic-lyric-pv-skill/tree/main/skills/ae-kinetic-lyric-pv
```

也可以将完整的 `skills/ae-kinetic-lyric-pv` 文件夹放入当前 Codex 支持的用户技能目录，保留参考文档和协议文件。目录发现规则见 [Codex 官方技能文档](https://learn.chatgpt.com/docs/build-skills)。安装后下一轮即可使用；若列表未出现，重启 Codex。

## 使用示例

```text
$ae-kinetic-lyric-pv 用我这次提供的歌曲和歌词制作完整黑白歌词 PV。完整分析参考片，创作带自嘲的 AI 主题屏幕歌词，重新绘制全部视觉素材，使用 AE 原生功能完成可编辑工程和经过验证的成片。使用我指定的项目目录和预算。
```

输入包括本次项目的音频、需要改编时使用的原词、可选参考视频、输出目录和创作约束。技能会区分“屏幕歌词改编”和“实际演唱歌词重录”：保留原歌曲时，不把屏幕中文改编宣称为音频中唱出的内容。参考片不是必需输入，仓库也不提供示例素材。

## 运行条件与范围

实际制作需要可访问且已授权的 After Effects，以及可操作 AE 或运行工程脚本的工具。FFmpeg/FFprobe 等媒体工具用于检查和导出。插画场景需要可用的图片生成能力或新绘制的画作；文字与几何画面可在 AE 内创建。技能不附带 Adobe 授权，不代为购买软件，不保证某个模型可用，也不要求安装第三方 AE 插件。

执行时应说明工具缺失和未完成的验证，不能用历史项目素材替代新创作。对外发布、付费购买，以及当前项目之外的清理，需要对应任务的授权。
