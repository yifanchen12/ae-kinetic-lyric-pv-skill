# AE 叙事歌词 PV 技能 · 黑白 / 彩色

简体中文 · [English](README.md) · [MIT 开源协议](LICENSE)

这是一个面向 Codex 的歌词 PV 制作技能，支持**黑白／彩色切换、视觉风格选择和歌词情绪选择**：使用 Adobe After Effects 原生图层、表达式、关键帧和按项目编写的脚本，把全片参考分析、歌词节拍对齐、新创作的画面、动态文字与成片验证串成完整流程。

**仓库仅包含制作方法。没有歌曲、现有歌曲的歌词、插画、立绘、截图、品牌标志、字体文件、成片或 AE 工程。每个新项目都重新创作视觉素材；参考视频仅用于分析，不从中提取画面或素材用于成片。**

## 技能包含什么

- 按完整时间轴分析参考视频，再对动作区间加密检查，不只挑选几个关键帧。
- 按选定的情绪创作屏幕歌词，按人声乐句对齐，同时保留当前项目选用的音频。
- 使用新创作的黑白或彩色插画、大字中文排版、低调信息栏、细线、左右交替构图与克制的转场。
- 以独立的文字、图像、形状和动画图层，搭建可编辑、无需第三方插件的 AE 工程。
- 先验证短片技术样例和代表性副歌，再进行全曲渲染。
- 检查完整解码、歌词时间、素材链接、文字可读性，并说明实际达到的音频保真程度。

这是指导制作的技能，不附带固定渲染器或可复用的媒体素材包。分辨率、帧率、主题、预算和构图按项目决定；1080p/60 fps 只是可调整的建议配置。

## 两种视觉模式

| 模式 | 视觉方向 | 选择方式 |
| --- | --- | --- |
| 黑白 | 黑、白、克制的灰阶，清晰线稿与明暗层次 | “使用黑白模式”或 `visual_mode: monochrome` |
| 彩色 | 新绘彩色插画与统一配色，保留相同的文字层级和动作方法 | “使用彩色模式”或 `visual_mode: color` |

未指定时默认黑白。AE 工程提供模式控制和集中配色控制，切换时保留歌词、时间轴及动画。需要两种模式真正可切换时，本次项目从头创作可用于彩色的画作，再在 AE 中调整黑白表现；仅有灰度画作时，需要重新创作彩色画作才能完成彩色版本。默认只导出指定模式，要求双版本时才导出两份。

## 风格、情绪与主题

三者独立选择，不互相绑定：

| 选项 | 示例 |
| --- | --- |
| 视觉风格 `visual_style` | 漫画、极简文字、电影感插画、水彩、复古印刷，或自定义组合 |
| 歌词情绪 `lyric_tone` | 抒情、热血、治愈、忧伤、浪漫、叙事、讽刺、自嘲，或自定义情绪 |
| 内容主题 `theme` | 由你决定；AI 主题不是必选项 |

自嘲仅是可选项，不作为默认。黑白也可以热血，彩色也可以忧伤。切换视觉风格可能需要新绘素材和重新设计构图；切换歌词情绪可能需要重写歌词。只有黑白／彩色按 AE 模式开关设计，这些变更都不复用历史素材。

```text
$skill-installer 安装这个仓库中的技能：https://github.com/yifanchen12/ae-kinetic-lyric-pv-skill/tree/main/skills/ae-kinetic-lyric-pv
```

也可以将完整的 `skills/ae-kinetic-lyric-pv` 文件夹放入当前 Codex 支持的用户技能目录，保留参考文档和协议文件。目录发现规则见 [Codex 官方技能文档](https://learn.chatgpt.com/docs/build-skills)。安装后下一轮即可使用；若列表未出现，重启 Codex。

## 使用示例

```text
$ae-kinetic-lyric-pv 用我这次提供的歌曲和歌词制作完整歌词 PV。选择彩色模式、水彩视觉、治愈情绪，主题是陪伴。完整分析参考片，重新绘制全部视觉素材，使用 AE 原生功能完成可编辑工程和经过验证的成片。使用我指定的项目目录和预算。
```

输入包括本次项目的音频、需要改编时使用的原词、可选参考视频、输出目录和创作约束。技能会区分“屏幕歌词改编”和“实际演唱歌词重录”：保留原歌曲时，不把屏幕中文改编宣称为音频中唱出的内容。参考片不是必需输入，仓库也不提供示例素材。

制作彩色版时，在请求里加上“使用彩色模式”。已有当前项目可以说：“切换为彩色模式，保留歌词、时间轴和动作，先验证一段预览。”也可以按相同方式切回黑白。全部视觉素材仍须来自本次项目的新创作。

## 运行条件与范围

实际制作需要可访问且已授权的 After Effects，以及可操作 AE 或运行工程脚本的工具。FFmpeg/FFprobe 等媒体工具用于检查和导出。插画场景需要可用的图片生成能力或新绘制的画作；文字与几何画面可在 AE 内创建。技能不附带 Adobe 授权，不代为购买软件，不保证某个模型可用，也不要求安装第三方 AE 插件。

执行时应说明工具缺失和未完成的验证，不能用历史项目素材替代新创作。对外发布、付费购买，以及当前项目之外的清理，需要对应任务的授权。
